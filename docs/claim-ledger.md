## Explicit non-claims

The project does not claim semantic code search, FaCoY equivalence, production latency, full-repository/user-trace representativeness, multi-host availability, malicious-server authentication, causal snapshots, globally latest reads, corpus-dependent score continuation, universal optimality, minimal repair bytes, or external peer acceptance. Successful reproduction does not replace real author approval and current submission declarations.
